# 飞书抖音直播采集

将抖音直播间的分享消息直接发送给飞书机器人，或发送：

```text
录制并分析 https://live.douyin.com/直播间ID
```

支持网页直播间、`v.douyin.com` 分享短链接及官方移动端 `webcast.amemv.com/douyin/webcast/reflow/{id}` 分享页。分享页参数需保留；普通视频短链接仍进入点播采集流程。

- 默认每 1 小时保存一段并分别分析、回传飞书，不限制总录制时长。
- 下播后保存最后不足一小时的片段；发送“取消最新直播任务”停止继续录制。
- 自动使用系统设置中的抖音 Cookies。若平台要求登录或风控，请更新该平台的 Cookies 文件后重试。
- 切段或断线重连可能有短暂间隔，不保证帧级无缝录制。

已用用户提供的篮球直播分享链接成功解析并实录约 5 秒；完整一小时录制和飞书回传尚未端到端实测。解析依赖 [StreamGet](https://github.com/ihmily/streamget)，平台接口变化可能影响可用性。
