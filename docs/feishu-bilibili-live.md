# 飞书 B 站直播采集

向已配置的飞书机器人发送完整直播间地址，例如：

```text
录制并分析 https://live.bilibili.com/123
```

也支持直接发送该直播间链接，或发送“录制并分析”加 `b23.tv` 直播分享短链接。入口会安全展开短链接，再按目标地址创建直播录制或点播采集任务，避免把直播误判为点播。其他平台直播支持见项目 README。

- 默认每 1 小时保存一个视频；录满一段后自动排队录制下一段，每段独立转写、分析并回传飞书。
- 不限制总录制时长，持续分段直到下播或主动取消。未开播会告知失败，不长期等待；开播后可重试。
- 下播时保留已录制的不足 1 小时片段。发送“取消最新直播任务”可停止最新录制并阻止继续分段。
- 未满 1 小时直播流就结束时，会重新检测直播间并尝试续录；连续两次检测到下播才确认结束。本段重连耗尽但未确认下播时，保存已有片段并排队续录，避免短暂断流终止整条任务。
- 每段标题包含段号。自动分段不重复计入每日提交次数；各段仍属于可查询的持久化工作流。
- 使用系统设置中已配置的 B 站 Cookies。Cookie 内容不会进入模型上下文或飞书通知。
- 切段包含封装、任务交接和重新连接过程，不保证帧级无缝连续录制。

部署时须同时重启飞书 Gateway 和桌面端管理的 Worker。自动化验证覆盖三段连续任务、短段、未开播、取消、工作流关联及通知入队；尚未完成真实一小时直播和飞书投递的端到端验证。
