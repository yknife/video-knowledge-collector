# 飞书小红书直播采集

从正在开播的小红书直播间复制分享链接，发给机器人，例如：

```text
录制并分析 https://www.xiaohongshu.com/livestream/直播间数字ID
```

支持 `/livestream/{数字ID}`、`/hina/livestream/{数字ID}`、`/livestream/{路由}/{数字ID}`
以及官方 `xhslink.cn`、`xhslink.com` 分享短链接。短链接先解析真实目标：直播间进入录制，笔记进入原有点播采集流程。
不要用用户主页或普通笔记链接代替直播间链接。

- 每 1 小时保存一段视频并分别分析、回传飞书，不限制总录制时长。
- 下播保存最后不足一小时的片段；发送“取消最新直播任务”停止继续分段。
- 未开播会返回小红书未开播提示，不会长期等待；系统设置的小红书 Cookies 自动用于解析。
- 每次重新连接及切段可能有短暂间隔，不保证帧级无缝录制。

实现复用 [StreamGet 的 RedNote 解析器](https://github.com/ihmily/streamget)。已验证短链分类、Cookie 传递和分段工作流；用户提供的真实直播分享链接已成功解析并实录约 5 秒。完整一小时录制及飞书结果投递尚未进行端到端实测。
