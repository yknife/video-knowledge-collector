# 样本人工复核卡

所有内容为人工构造，不代表真实媒体或模型质量。引用时间单位均为毫秒，直播时间为各分段内时间。

| 样本 | 人工预期 |
| --- | --- |
| A | 作者建议每次新增资料都全量重建索引；证据 a2，10—20 秒。 |
| B | 同为检索增强主题，作者建议增量索引；证据 b2，10—20 秒。与 A 可并列，但 B 没有证明其普适性。 |
| C | 明确反对“每次全量重建”；证据 c2，10—20 秒。同时承认样本不足，不能据此断言增量始终更好。必须保留 A/C 观点冲突。 |
| D | 盆栽浇水与检索增强无关；不能因泛词“检查”建立错误主题关联。 |
| E | 四类分析均为降级结果；只建警示视频页，不提升为确定知识。 |
| F | 与 A 同 media_id，Transcript 和分析版本提高；应更新原视频页的 revision，并保留 A 的历史快照。 |
| L1/L2 | 同一个 session_id 的不同 media_id；各有视频页及同场目录，分段内时间不能按文件序号拼接。两段不能当成两个独立来源佐证。 |
