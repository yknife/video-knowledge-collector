# 飞书新浪微博采集

飞书机器人支持新浪微博点播视频、微博直播和官方 `t.cn` 分享短链接。普通微博链接需带明确意图，例如：

```text
采集并分析这个微博：https://weibo.com/用户数字ID/微博ID
```

直播链接可以直接发送，也可以加上“录制并分析”。当前接受以下常见格式：

- `https://weibo.com/l/wblive/p/show/1022:直播ID`
- `https://weibo.com/u/主播数字ID`
- `https://t.cn/分享短码`

短链接会先在受限网络访问规则下解析真实目标，再区分点播和直播。跨平台跳转、非公网地址、伪造域名和不受支持的页面形态会被拒绝。

直播默认每 1 小时保存一段并自动续录，总时长默认不限。主播下播时会保存最后不足 1 小时的片段，每个片段分别进入转写、Hermes 知识分析和飞书结果回传。发送“取消最新直播任务”可以停止继续录制。

如微博要求登录或触发风控，请在“系统设置 → 平台 Cookies”中为“微博”选择 Netscape 格式的 `cookies.txt`，然后重试任务。Cookies 仅传给对应媒体解析器，不会写入任务日志。

实现使用 yt-dlp 采集微博点播，使用 StreamGet 解析微博直播流，并复用 VKC 现有的 FFmpeg 分段录制、ASR、分析与飞书通知流程。自动化测试已覆盖 URL 形态、短链平台约束、Cookies 传递、开播/未开播解析和每小时分段工作流；真实直播仍取决于当时房间状态和微博接口可用性。
